# Portfólio de ZakiSC

Site estático em português, feito com HTML e CSS, com uma seleção de projetos públicos do perfil [ZakiSCzip](https://github.com/ZakiSCzip).

## Editar

- `index.html`: textos, projetos e links.
- `style.css`: cores, tipografia e layout responsivo.

Não exige instalação de dependências. Abra `index.html` no navegador para visualizar.

## Publicar no GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)`.

Endereço previsto: https://zakisczip.github.io/

Os projetos de terceiros e forks mantêm seus créditos nos repositórios de origem.
